# 🏘 小镇模拟游戏（星露谷风）

一个基于 QQ 机器人的小镇模拟经营游戏，由 Python 脚本驱动（OpenClaw + QQ 机器人渠道）。

## 🎮 主要玩法

创建角色 → 在小镇中移动探索 → 打工赚钱、吃喝恢复精力、学习/玩街机/打麻将提升熟练度 → 与 NPC 聊天刷好感（好感高有礼物🎁）→ 玩家之间互动（打招呼/转账/偷/打架）→ 银行存钱吃利息 → 排行榜竞争 → 干坏事会被抓进警察局坐牢⛓

- **游戏时间 = 现实时间**，精力每 5 分钟恢复 1 点（上限 100）
- 状态保存在 `state.json`（运行时数据，不入库）

## 📍 小镇场景（10 个）

世纪联华 · 机厅 · 星巴克 · KFC · 小吃店 · 公寓 · 学校 · 警察局 · 银行 · 麻将馆

## 📖 命令大全（含别名）

### 基础
| 命令 | 别名 | 说明 |
|---|---|---|
| `创建角色 名字` | create / 注册 | 加入小镇 |
| `改名 新名字` | rename / 改名卡 | 修改角色名 |
| `状态` | status / 我的状态 | 查看属性 |
| `地图` | map / 小镇 | 查看小镇布局 |
| `排行榜` | rank | 熟练度排行 |
| `关系` | rel / 好感 | 查看 NPC 好感度 |
| `帮助` | help / 操作 / 菜单 | 操作手册 |

### 移动
| 命令 | 别名 | 说明 |
|---|---|---|
| `去 场景名` | move / 前往 / 去往 | 移动到场景 |

### 场景互动
| 命令 | 别名 | 说明 |
|---|---|---|
| `互动 NPC名` | chat / 聊天 | 与 NPC 聊天刷好感 |
| `做 动作` | do | 执行场景动作（吃喝/学习/玩街机/打麻将等） |
| `活动` | act / 能做 | 查看当前场景可做动作 |
| `打工` | work / 上班 | 当前场景赚钱 |
| `休息` | rest | 公寓回精力 |
| `学习` | study | 学校加熟练度 |
| `玩街机` | play / 玩游戏 | 机厅加熟练度 |
| `打麻将` | mahjong / 麻将 / 打牌 | 麻将馆（30%赢/40%平/30%输） |
| `吃` | eat / 吃东西 | 吃当前场景食物 |

### 玩家互动
| 命令 | 别名 | 说明 |
|---|---|---|
| `打招呼 玩家名` | hi / hello | 玩家好感 +2（需同场景） |
| `转账 玩家名 金额` | transfer / 给钱 | 给玩家金币（需同场景） |
| `偷 玩家名` | steal / 偷钱 / 盗窃 | 40% 得手偷 10-20%，60% 进局子（1-5分钟） |
| `殴打 玩家名` | fight / 打架 / 揍 | 50% 打掉对方 20 精力，50% 反被揍 |

### 银行
| 命令 | 别名 | 说明 |
|---|---|---|
| `存钱 金额` | deposit / 存款 | 存款防偷 |
| `取钱 金额` | withdraw / 取款 | 取款 |
| `查账` | account / 账户 | 查看存款，每 24 小时结算利息（-1%~+5% 真随机） |

### 管理员专用（需权限）
| 命令 | 说明 |
|---|---|
| `发放 玩家名 金额` | 发金币 |
| `扣除 玩家名 金额` | 扣金币 |
| `关押 玩家名` | 关进警察局（1-5分钟） |
| `释放 玩家名` | 特赦出狱 |
| `公告 内容` | 小镇公告 |
| `查玩家 玩家名` | 查看玩家档案 |

## 🚀 使用

```bash
python3 town.py <命令> --uid <openid> [--name <昵称>] [参数...]
```

示例：
```bash
python3 town.py 创建角色 --uid 9A94006798499C6C8BCB027837CA3718 --name 皇帝
python3 town.py 去 --uid 9A94006798499C6C8BCB027837CA3718 机厅
python3 town.py 打工 --uid 9A94006798499C6C8BCB027837CA3718
```

## 📁 文件说明

- `town.py` — 游戏主程序（单文件，无第三方依赖）
- `state.json` — 运行时玩家数据（git 忽略，不提交）
