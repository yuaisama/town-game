# 🏘 小镇模拟游戏（星露谷风）

一个基于 QQ 机器人的小镇模拟经营游戏，由 Python 脚本驱动（OpenClaw + QQ 机器人渠道）。

## 🎮 主要玩法

创建角色（选性别）→ 在小镇中移动探索 → 打工赚钱、吃喝恢复精力、学习/街机/麻将提升属性 → 与 NPC 聊天/帮忙/谈心刷好感 → 玩家间互动（打招呼/转账/偷/打架/求婚结婚）→ 银行存钱吃利息 → 机厅四台机器 → 排行榜争霸 → 干坏事进警察局坐牢⛓

- **游戏时间 = 现实时间**，精力每 5 分钟恢复（智力加成），上限由体质决定
- 公寓**休息 30 分钟回满精力**（睡觉中不能行动）
- 状态保存在 `state.json`（运行时数据，不入库）

## 📍 小镇场景（10 个）

世纪联华 · 机厅 · 星巴克 · KFC · 小吃店 · 公寓 · 学校 · 警察局 · 银行 · 麻将馆

## 🧬 角色属性

### 五项战斗/生活属性（STR/INT 初始 5，其余 0）

| 属性 | 成长方式 | 效果 |
|---|---|---|
| 💪 **力量 STR** | 体力打工、舞萌 | 殴打成功率/反制率（力量差，上限85%） |
| 🦾 **敏捷 DEX** | 玩街机、舞萌（衰减：5×100/(100+DEX)） | 偷窃成功率(10%+0.4%/点，上限70%)、偷取比例(0.2%/点，上限70%) |
| 🧠 **智力 INT** | 学习、智力打工 | 打工收益 +1%/点；精力恢复 +INT/20 |
| 🛡 **体质 CON** | 吃喝、休息 | 精力上限 100+CON×2 |
| 🍀 **幸运 LUK** | 无途径（固定0） | 麻将胜率、偷窃收益 |

### 基础属性
| 属性 | 初始 | 规则 |
|---|---|---|
| ⚡ 精力 | 100 | 上限=100+CON×2；每5分钟恢复 1+INT//20 |
| 💰 金钱 | 100 | 可被偷 |
| 💞 NPC好感 | 0 | 聊天+3~5/帮忙/谈心；礼物：好感25→20金、50→30金、80→50金；好感>50互动有概率收30~100金礼物 |
| 👥 玩家好感 | 0 | **范围 -300~+200**：0陌生人/50熟人/80挚友/100可求婚/200夫妻 |
| 🏦 存款 | 0 | 24h 利息 -1%~+5% |
| 🚨 案底 | 0 | 每次犯罪+1 |

## 💍 结婚系统

- 双方互有好感 ≥100 + 异性 + 同场景 → 求婚 → 对方「同意」→ 结婚
- 夫妻特权：**花金币项目全部 8 折**、互动好感翻倍

## 🚀 使用

```bash
python3 town.py <命令> --uid <openid> [--name <昵称>] [参数...]
```

示例：
```bash
python3 town.py 创建角色 --uid 9A94006798499C6C8BCB027837CA3718 --name 皇帝 男
python3 town.py 去 --uid 9A94006798499C6C8BCB027837CA3718 机厅
python3 town.py 舞萌 --uid 9A94006798499C6C8BCB027837CA3718
python3 town.py 打工 --uid 9A94006798499C6C8BCB027837CA3718
```
